# 首次 IgH 空载单轴运动（2026-09-09）

普通内核 `7.0.0-31-generic` 下已完成真实电机的 90 counts 往返及正常失能。用户明确说明电机未连接机构、允许转动，并确认可以切断电源。本轮只连接一台 Diamond；没有接入机器人机构、五轴联动或 IK/PVT 轨迹流。

## 结果

原始记录：`build/single-motion-2026-09-09-155749.json`、`.log`、`-kernel.log`。摘要、逐阶段统计与文件 SHA256 见 [证据文件](single_motion_evidence_2026-09-09.json)。

位置轨迹实际跟随了目标。向外运动阶段反馈从约 -506000552 到 -506000461，返回阶段回到约 -506000556，随后保持在原点附近。循环收尾读到 -506000552，PREOP 的独立 SDO 读到 -506000553；初始 SDO 为 -506000554，这种几个计数的波动不应解释成已标定的重复定位精度。

状态字依次出现 `0x0240`、`0x0221/0x0231`、`0x0233/0x1233`、`0x1237/0x1637`，结束为 `0x1640`。按 CiA402 状态掩码识别，最后仍为 Switch On Disabled；不能用整字必须等于 `0x0240` 来判断失能。正常退出继续发送控制字 0 一秒，最终连续至少 200 ms 有效 PDO 反馈确认失能。没有执行实际断电、拔线或急停试验。

启动日志仍出现一次 5 秒未同步警告；进入 OP 后差值继续收敛，达到程序的持续稳定条件后才进入回读及运动。本轮循环和释放阶段均未记录 AL 0x001A。

## PDO 计数的定位及有限兼容

专项记录 `build/pdo-count-write-2026-09-09-154935.json`：在健康、失能、PREOP 下，向 `1C12/1C13:0` 写 0 和 1，回读始终为 2；向 `1600:0` 写 0 和 5，回读始终为 10；向 `1A00:0` 写 0 和 6，回读始终为 12。所有这些写操作均收到成功响应。手册默认映射表也列出 Rx 10、Tx 12，但没有证明此固件应固定返回容量。因此结论是**已复现固定计数回读行为，固件内部原因尚未确认**。

同时写回完整的期望前缀并清零所有未使用槽，消除了此前 Rx 尾部的旧转矩/模式条目。运动入口只接受本台身份、固件 `1.6.5.0.2.1.8.8`、已观察到的计数组合、正确前缀和全零未用槽；没有普遍忽略 PDO 差异。

本次运行中，在控制字始终为 0 时，先向 PDO 目标位置交替写入初始位置 +13、-17 和 0 counts。每阶段稳定后，用独立异步 SDO 核对 `607A` 目标、`6040` 控制字、`6071` 零转矩目标、`6060` 模式、`6064` 位置反馈及 `603F` 错误码。三个阶段均通过，之后才执行使能。此结果验证了该配置下的有效数据通道，不能当作固件计数已修复或任意映射都兼容。

## 保护参数及失败记录

临时写入并回读：`6072/60E0/60E1=30`，`6065=128`，`6066=20`，`607D` 上下限为新鲜位置 ±512 counts；主机策略另外限制位移 256 counts、跟随误差 64 counts、反馈转矩 100，并检查端点到位误差。手册描述 `60E0/60E1` 为各运动模式的转矩限制、单位额定转矩的 0.1%，因此 30 对应 3%。这些配置及一次空载测试不能证明所有保护失效场景已验证。

首次尝试 `pdo-echo-disabled-2026-09-09-155537` 在写负数软件位置限位时失败：CLI 把负数当作选项。尚未启动循环或使能，部分较保守的限值被保留。已修复为使用 `--` 分隔值，并在同台健康失能状态下按原始日志恢复全部基线、回读核对后才开始成功的运动试验。成功记录包含 `recovered_limit_baseline`。此失败没有省略。

脚本默认失能校验；真实运动需要显式参数。子进程异常后尝试持续失能；若反馈或状态无法确认，不自动复位/重试，也不恢复较宽限值。用户态程序和普通内核仍不能保证断线、进程被强杀或系统卡死时的物理停车。

## 代码及后续范围

独立 `igh_motion_probe` / `probe_motion.py` 接入已测试的小幅往返策略；旧 `igh_disabled_probe` 仍只发送控制字 0。增加端点未到达拒绝条件和参数恢复测试，最终 **13 组 CTest 全部通过**，Release 构建通过。五轴 `hardware_validated` 保持 false；PMAC 修复分支未改变。

下一步可做单轴重复性和长时测试、受控异常停止，再接入多轴及上层 IK/PVT。当前结论是“普通内核上的单轴空载运动链路已走通”，不是完整 PMAC 替代验收。
